= FF Logistic
:description: One logistics product, built as a modular monolith and as microservices, on one platform, and compared.

One logistics product, built twice: as a *modular monolith* and as *microservices*, on the same platform, behind the same switch, and then measured.

== The question

"Should this be a monolith or microservices?" is usually answered by comparing a real system with an imagined one. Here both are real. The business rules are written once; only the wiring between the business areas differs. Both run against the same database tables, the same Kafka topics and the same identity service, and one Git commit decides which of them is running.

Think of one recipe book and two kitchens. In the first kitchen, every cook stands at the same counter: passing a dish is handing it over. In the second, each cook has a room of their own, and dishes go through hatches, with a ticket, sometimes late. The recipes are identical. What differs, and what this project measures, is everything about the hatches.
